# Heat Health Action Plan Registry

This is a collaborative effort of the Global Heat Health Information Network (GHHIN) and Columbia University SPARK Lab to create a centralized, openly accessible inventory of heat-health action plans. Submitted plans will be hosted on a public site upon approval for open access learning and research.
