# Heat Health Action Plan Registry

This is a collaborative effort of the Global Heat Health Information Network (GHHIN) and Columbia University SPARK Lab NYC to create a centralized, openly accessible inventory of heat-health action plans. Submitted plans will be hosted on a public site upon approval for open access learning and research.

[![Website](https://img.shields.io/badge/View%20Website-0b5fa4?style=for-the-badge&logo=google-chrome&logoColor=white)](https://sparklabnyc.github.io/heat_health_action_plan_registry/)

## Downloading the plans

- **All plans at once:** [Download the zip](https://github.com/sparklabnyc/heat_health_action_plan_registry/releases/download/plans-latest/hhap_plans.zip). It contains every plan, plus the plan index (`plans_index.csv`). It's also on the [Releases page](https://github.com/sparklabnyc/heat_health_action_plan_registry/releases/tag/plans-latest) and updates automatically when plans are added.
- **Individual PDFs:** browse the [`pdfs/`](https://github.com/sparklabnyc/heat_health_action_plan_registry/tree/main/pdfs) folder. 
- **Plan information:** [`plans_index.csv`](https://github.com/sparklabnyc/heat_health_action_plan_registry/blob/main/plans_index.csv) lists each plan's title, country, state/province, city, year, language, organization, source URL (when available), and PDF link. The same data is available as [`plans_index.json`](https://github.com/sparklabnyc/heat_health_action_plan_registry/blob/main/plans_index.json).
